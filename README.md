# Maths-v3

An animated mathematical-art experiment built around the curve **y = -1/x**. `index.html` displays changing x and y values alongside the visualisation and defines the on-screen controls. The repository also includes the music asset `music.mp3`.

## Preview locally

Open `index.html` in a modern browser. Alternatively, run a local server from the project folder:

    python -m http.server 8000

Then visit http://localhost:8000.

## Explore and customise

Keep displayed values aligned with the plotted curve when changing the animation or interaction. Preserve the relative path to `music.mp3` if replacing the audio file.
