# Maths-v3

An animated mathematical-art experiment built around the curve **y = -1/x**. The root `index.html` displays changing x and y values alongside the visualisation and defines the on-screen controls. The project also includes the music asset `music.mp3` in the root.

## Preview locally

Open `index.html` in a browser. Alternatively, run a local server from the project folder:

    python -m http.server 8000

Then visit http://localhost:8000. Reload the page after editing to review the animation and controls.

## Explore and customise

Keep displayed values aligned with the plotted curve when changing the animation or interaction. Preserve the relative path to `music.mp3` if replacing the audio file.
