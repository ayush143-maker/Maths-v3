# Maths-v3

An animated mathematical-art experiment built around the curve **y = -1/x**. The page displays changing x and y values alongside the visualisation, and the repository includes a music asset.

## Preview locally

Open `index.html` in a modern browser, or run a local server:

    python -m http.server 8000

Visit http://localhost:8000.

## Explore and customise

The visualisation and on-screen controls are in `index.html`. Keep displayed values aligned with the plotted curve when changing the animation or interaction. Preserve the relative path to `music.mp3` if replacing the audio file.
